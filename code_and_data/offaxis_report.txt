  EFL = 99.9999 mm    EPD = 25.4 mm    F/# = 3.94

  入瞳距 = -0.0000 mm（≈0：光阑就在第一个面上）
  像面：d 光近轴焦点，z = 103.9559 mm
  光线网格：六角极坐标 6 环 = 127 条/视场
  说明：像差分析用单色 d 光 —— 三次像差理论本就是单色的，混色会污染判据。

[三] 彗差：切向扇的三次拟合  δy(ρ) = a₁ρ + a₂ρ² + a₃ρ³
      视场     a₁ (µm)     a₂ (µm)     a₃ (µm)   解读
      0°        -7.6        -0.0        11.2   纯奇次：球差
      3°       -70.5       -59.4        10.8   偶次项主导：彗差 73% 权重
      5°      -183.2       -99.0        10.2   偶次项主导：彗差 51% 权重
  彗差系数随视场：-19.77 µm/度（线性拟合）
  比值 a₂(5°)/a₂(3°) = 1.665，理论值 5/3 = 1.667  → 彗差 ∝ θ¹，确认是三级彗差
  重要：离焦只产生奇次项 a₁ρ，不会伪造 a₂ —— 所以 a₂ 是干净的彗差量。

[四] 像散与场曲：切向 / 弧矢焦点
      视场    z_T (µm)    z_S (µm)        |像散|   z_med (µm)     T面RMS     S面RMS
      0°        -1.9        -1.9         0.0         -1.9       2.3       2.3

  注：z 为相对平面像面的位移，负 = 朝透镜方向；z_med = 两者中点（最小弥散圆附近）

  · 像散 |z_T − z_S|：3° 时 260 µm，5° 时 718 µm
    比值 2.76，理论 (5/3)² = 2.78  → 像散 ∝ θ²，确认是三级像散
    切向焦面比弧矢焦面更靠近透镜（z_T 更负），这与正透镜的 Petzval 面朝物方弯曲一致。
  · 三个焦面都随 θ² 弯曲：z_T ≈ -54.4·θ² µm，z_S ≈ -25.7·θ² µm，z_med ≈ -40.1·θ² µm
  · Petzval 面 z_p = (3·z_S − z_T)/2 ≈ -11.4·θ² µm
    切向偏离 : 弧矢偏离 = 3.00 : 1（光阑在透镜上的薄透镜理论值 3 : 1，实测吻合）
  · Petzval 半径：实测 R_p = y²/(2|z_p|) = 133.7 mm （y = f·tanθ）
                理论 1/R_p = Σ(φ_i/n_i) = 0.00728 mm⁻¹ → R_p = 137.4 mm（偏差 3%，薄透镜近似忽略了厚度与入射高）

[六] 缩光圈能不能救？
  口径           F/#   r_A µm        1°        2°        3°        5°
  25.4         3.9     2.82       8.0      20.7      41.7     109.0
  12.7         7.9     5.64       3.4       9.7      20.2      53.6
  8.0         12.5     8.96       1.7       5.6      12.2      33.2
  说明：像差 ∝ 口径²（f/3.9→f/12.5 口径缩 3.2 倍，像差缩 ~10 倍），
        但艾里斑 ∝ 口径⁻¹ 也在长大，所以 RMS/r_A 只改善约 3 倍 —— 缩光圈治不了场曲。

[七] 结论
  1) 轴上（0°）RMS = 3.5 µm（1.2 r_A），圆斑、无拖尾 —— 任务 06 的球差/色差校正确实到位。
  2) 3° 时 RMS = 41.7 µm（15 r_A），斑已经拉成 141 µm 长的彗星；5° 时 109 µm（39 r_A），比轴上大 31 倍。
  3) 这个系统的可用视场只有 ±0.7°（2×艾里），±1.6° 已经肉眼可见发软，±2.4° 彻底崩溃。
     若允许每个视场单独调焦，崩溃点后移到 ±3.4°——
     说明限制不是'调焦没调好'，而是像散+彗差本身的波前畸变。
  4) 崩溃的元凶排序（5° 时）：像散 > 场曲 > 彗差。
     像散把 T/S 焦面拉开 718 µm，而焦深只有 ±18 µm —— 任何平面探测器都同时接不住两条焦线。
  5) 想要宽视场，这个两片结构在物理上做不到，必须引入新的自由度：
     · 场镜/平场镜（field flattener）：把 Petzval 面压平，最省事的办法
     · 移动光阑（stop shift）：光阑前移/后移可显著改变彗差与像散的配比
     · 换成 Cooke 三片或 Double-Gauss：用正负分离结构独立控制场曲
     · 或直接限制视场 ≤ ±1.5°，用在这个口径上它才是一支合格的镜头
